Flujo de Operación — Ciclo de Scan

1. Encendido e Inicialización

Configurar relojes PLL, GPIO, SPI, UART. Verificar watchdog.

2. Auto-diagnóstico (POST)

Test RAM, test Flash, verificar módulos de expansión y comunicaciones.

3. Cargar Programa de Usuario

Leer desde Flash externa W25Q64. Verificar CRC del programa.

4. Leer Entradas (cada ciclo)

Leer 12 DI físicas + módulos expansión. Actualizar imagen de proceso.

5. Ejecutar Programa Usuario

Procesar lógica Ladder/ST. Actualizar temporizadores y contadores.

6. Escribir Salidas

Actualizar 8 DO físicas + módulos expansión.

7. Comunicaciones + Watchdog

Procesar Modbus RTU. Reset watchdog. Tiempo ciclo típico: 1–10 ms.

Ciclo de Scan — Código C

void PLC_ScanTask(void *pvParameters) {
    TickType_t xLastWakeTime = xTaskGetTickCount();
    while(1) {
        /* 1. Leer entradas */
        PLC_ReadPhysicalInputs();    // PA0-PA7, PB0-PB3
        PLC_ReadExpansionInputs();   // SPI2 → módulos CS1-CS8

        /* 2. Ejecutar programa usuario */
        PLC_ExecuteUserProgram();    // Runtime IEC 61131-3
        PLC_UpdateTimers();          // TON, TOF, TP
        PLC_UpdateCounters();        // CTU, CTD, CTUD

        /* 3. Escribir salidas */
        PLC_WritePhysicalOutputs();  // PC0-PC7
        PLC_WriteExpansionOutputs(); // SPI2 → módulos

        /* 4. Reset watchdog */
        HAL_IWDG_Refresh(&hiwdg);
        WDG_External_Kick();         // MAX706 → PD11

        /* 5. Esperar próximo ciclo */
        vTaskDelayUntil(&xLastWakeTime, pdMS_TO_TICKS(10));
    }
}

Actualización de Firmware (OTA)

Método 1 — USB DFU

Mantener BOOT0 alto durante encendido → STM32 entra en bootloader USB → STM32CubeProgrammer carga el nuevo .bin

Método 2 — SWD Debug

Conectar ST-Link V2 al conector J_SWD (IDC 2×5, 1.27mm) → cargar desde STM32CubeIDE u OpenOCD

Método 3 — Modbus (futuro)

Comando Modbus de inicio → transferir firmware en bloques 256 bytes → verificar CRC → reiniciar

Trama del Protocolo SPI (16 bits)

Comando (CPU → Módulo):
  Byte 1: [CMD 7:4][ADDR 3:0]   CMD: 0x1=LeerES 0x2=EscribirSalidas 0xF=Identificar
  Byte 2: [DATA 7:0]

Respuesta (Módulo → CPU):
  Byte 1: [STATUS 7:4][TYPE 3:0]  STATUS: 0x0=OK 0x1=Error 0xF=Ausente
  Byte 2: [DATA 7:0]

TYPE:  0x1=EXP-8DI  0x2=EXP-8DO-R  0x3=EXP-8DO-T
       0x4=EXP-4AI  0x5=EXP-2AO    0x6=EXP-ETH  0x7=EXP-CAN

Identificación Automática al Encendido

void PLC_DetectExpansionModules(void) {
    for(int slot = 0; slot < 8; slot++) {
        CS_Select(slot);                                 // PE0–PE7
        uint8_t resp = SPI_SendCommand(CMD_IDENTIFY, 0);
        CS_Deselect(slot);
        if((resp >> 4) == STATUS_OK) {
            modules[slot].present = true;
            modules[slot].type    = resp & 0x0F;
            PLC_AssignModuleVariables(slot, modules[slot].type);
            // %IX[slot+1].0 para EXP-8DI en slot 1
        }
    }
}

  105 mm + (8 × 35 mm) = 385 mm en riel DIN

  ● Conector lateral IDC-20 (bus expansión)
  ● Guía de alineación plástica
  ● Sin tornillos — conexión por presión

Consideraciones de Instalación

  • Orientación vertical recomendada (mejor ventilación natural)
  • Espacio libre mínimo: 25mm superior e inferior, 10mm laterales
  • Temperatura ambiente máxima: +60°C (hasta +70°C con ventilación forzada)
  • Mínimo 50mm de separación de transformadores y resistencias de potencia
  • Mínimo 100mm de variadores de frecuencia (EMI)
  • Cables de campo y de potencia: máximo 2.5mm²
  • Canaleta separada para cables de señal y cables de potencia
  • No montar en orientación invertida (calor acumulado en componentes)

Pruebas de Prototipo (Fase de Desarrollo)

PT-001 ALIMENTACIÓN ─────────────────────────────────────────────
  Equipo: Fuente de laboratorio + multímetro + osciloscopio
  ✓ +5V en rango 4.75–5.25V (rango entrada 19.2–28.8V)
  ✓ +3.3V en rango 3.2–3.4V
  ✓ Sin daño por inversión de polaridad (D_POL P600M)
  ✓ Sin daño por transitorio 1kV/1µs (MOV+TVS)
  ✓ Ripple +5V <50mV pp / +3.3V <20mV pp

PT-002 ENTRADAS DIGITALES ──────────────────────────────────────
  Equipo: Fuente 24VDC + PC con QModMaster
  ✓ Los 12 canales detectan correctamente
  ✓ Detección entre 18VDC y 30VDC
  ✓ Tiempo de respuesta <5ms
  ✓ Sin falsas activaciones con ruido 1kHz

PT-003 SALIDAS A RELÉ ──────────────────────────────────────────
  Equipo: PC Modbus + multímetro + carga 1A/24VDC
  ✓ LED rojo enciende al activar por Modbus
  ✓ Resistencia contacto NA <0.5Ω
  ✓ Sin pegado de contactos tras 100 ciclos carga
  ✓ Tiempo de conmutación <10ms

PT-004 RS-485 MODBUS ────────────────────────────────────────────
  Equipo: Adaptador USB-RS485 + Modbus Poll/QModMaster
  ✓ Comunicación correcta a 1200–115200 bps
  ✓ CRC correcto en todas las tramas
  ✓ Funcionamiento con cable de 100m
  ✓ Sin errores con variador de frecuencia cercano

PT-005 FIRMWARE / SCAN ─────────────────────────────────────────
  Equipo: OpenPLC Editor + osciloscopio en GPIO
  ✓ Tiempo de ciclo <20ms bajo carga
  ✓ Watchdog genera reset si no recibe kick en 1.6s
  ✓ RTC mantiene hora correcta con batería CR2032
  ✓ Sin errores después de 1 hora a 50°C ambiente

Programa Ladder de Prueba (Structured Text)

(* ColPLC v1.0 — Programa de prueba básico IEC 61131-3 *)
PROGRAM PLC_TEST
VAR
    timer1:   TON;
    counter1: CTU;
END_VAR

(* Red 1: Reflejo entradas → salidas *)
DO1 := DI1;  DO2 := DI2;  DO3 := DI3;  DO4 := DI4;
DO5 := DI5;  DO6 := DI6;  DO7 := DI7;  DO8 := DI8;

(* Red 2: DO1 parpadea cada 1 segundo *)
timer1(IN := NOT timer1.Q, PT := T#1000ms);
IF timer1.Q THEN DO1 := NOT DO1; END_IF;

(* Red 3: Contador en DI9, reset en DI10 *)
counter1(CU := DI9, R := DI10, PV := 100);

(* Red 4: DO5 activo cuando contador >= 10 *)
DO5 := (counter1.CV >= 10);
END_PROGRAM
